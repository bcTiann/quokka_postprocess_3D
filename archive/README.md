# Historical material

Nothing under this directory is used by the current process, plot or table
builder. Current instructions are in the [root README](../README.md),
[directory guide](../docs/repository_layout.md) and
[code walkthrough](../docs/code_walkthrough.md).

## Source and notes

| File | Contents |
|---|---|
| `code/retired_experiments_20261006.tar.gz` | 87 unused source/test/parameter files and three older source versions containing retired functions |
| `documents/historical_notes_20261006.tar.gz` | Former notebook notes, historical workflow documents, earlier source archives, and the old readability plan |
| [manifest.json](manifest.json) | Original paths, reasons for retirement, SHA-256 values, and active-file moves |

The retired code includes Saha CII, CHIANTI CIE, old three-regime temperature
logic, single-line Cloudy CII lookup, fixed-axis DESPOTIC migration, and old
cached-HDF5/replotting experiments. The current analytic hydrogen calculations
remain in `src/quokka2s/physics/hydrogen_emissivity.py`.

The 34 project-specific Cloudy parameter experiments are also archived.
Current build parameters are generated by `tools/cloudy/build_cloudy_emission_table.py`;
the pinned upstream source and ten upstream-style examples remain in `vendor/`.

All retired files were recovered from the frozen dirty working tree and read
back from the archive to verify their hashes before removal. Archived scripts
describe their historical environments and may require their original inputs
and dependencies; they are not alternate current commands.

To inspect an archive without extracting it into the active code tree:

```bash
tar -tzf archive/code/retired_experiments_20261006.tar.gz
tar -tzf archive/documents/historical_notes_20261006.tar.gz
```

## Large local files

`local/` is outside Git. Existing large files were moved, not recomputed or
deleted. It holds the former root `data/`, `intermediates/`,
`intermediates_z2ray_harmonic/`, `logs/`, `work/`, `tmp/`,
`output_tables_3D_GOW_LVG/`, `TablePlots_GOW_LVG/`, and `to-baochen/` directories.
Historical run results are under `local/output/`.

Current snapshot/table inputs stay in `inputs/`; current numerical products,
figures and every manuscript directory stay in `output/`. The Cloudy exports
needed by the retained radiation-field figure tools are preserved in
`runtime/cloudy_eightline/sed/`.

The frozen source/product copies and the cleanup comparison reports are in
`output/repo_reorganization_20261006/`. This local evidence is separate from
the smaller historical archives above.
